# Identidade visual — CRM

Estas regras valem para **todas** as telas do projeto. Se uma tela não seguir isto, está errada.

## Clima

Ferramenta profissional, limpa e confiante. Um produto, não um template.

## Cores

| Uso | Cor |
| --- | --- |
| Fundo da página (claro levemente quente) | `#FAFAF7` |
| Superfícies (cards, barras, campos) | `#FFFFFF` |
| Borda sutil | `#E6E4DE` |
| Texto principal (grafite) | `#17181C` |
| Texto de apoio | `#6B6E76` |
| Destaque (ações e elementos ativos) | `#1D4ED8` |
| Destaque em hover | `#1E40AF` |

Uma única cor de destaque: azul-cobalto. **Nenhuma outra cor de marca.**

### Etapas do funil

Usadas **só** nas etiquetas de etapa, em nenhum outro lugar:

| Etapa | Cor |
| --- | --- |
| novo | `#64748B` |
| em contato | `#D97706` |
| proposta | `#7C3AED` |
| cliente | `#15803D` |

## Tipografia

- **Manrope** (Google Fonts) em tudo.
- Títulos em peso forte (700/800), textos em peso normal (400/500).
- Tamanhos generosos e hierarquia clara: cada nível de título é visivelmente diferente do anterior.

## Formas e espaço

- Cantos levemente arredondados: **10px**.
- Bordas visíveis (`#E6E4DE`) em vez de sombras pesadas.
- Bastante respiro entre os elementos.

## Proibido

- Gradientes
- Efeito de vidro / desfoque
- Emojis na interface
- Sombras exageradas
- Animações chamativas

Se parecer template de IA, está errado.
