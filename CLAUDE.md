# Regras do projeto — CRM

Leio este arquivo em toda sessão. Valem para tudo que eu fizer aqui.

1. **`prd.md` e `design.md` são a fonte da verdade.** Consulto os dois antes de qualquer tarefa. Se o pedido conflita com eles, aviso antes de escrever código.
2. **Prioridade máxima é simplicidade.** A solução mais simples que resolve o problema. Sem abstração criada "para depois".
3. **Base é Next.js** (o mesmo do React): telas e servidor no mesmo projeto, do jeito que o mercado constrói hoje.
4. **Explicações em português direto**, sem jargão desnecessário. Se um termo técnico for inevitável, explico em uma linha.
5. **Nenhuma senha ou chave dentro do código.** Segredos ficam em arquivo próprio (`.env.local`), que nunca vai para o repositório.
6. **Somente o que foi pedido em cada etapa.** Nada de extras por conta própria. Se eu vir algo que vale a pena, sugiro — não implemento.
7. **Antes de mudanças grandes, explico em 2 frases** o que vou fazer, e espero o ok.
8. **Toda entrega termina com "como testar"**: os passos exatos para você conferir que funcionou.
